# Шахматы 1.1

Русскоязычная PWA для игры и обучения. После появления статуса «Готово к офлайн-игре» доска, Stockfish, уроки, задачи и анализ доступны без сети. Сетевой режим использует отдельный игровой сервер.

## Локальный запуск

Из корня репозитория выполните `node server/main.js` под Node.js 24 LTS и откройте http://127.0.0.1:8787/chess/. Для одной только PWA достаточно статического HTTP-сервера в корне проекта. На устройствах вне localhost нужен HTTPS. Рабочие зависимости из npm устанавливать не требуется.

## Игра

В главном меню выберите игру с компьютером или вдвоём. Можно задать цвет и часы, включая собственный контроль с добавлением. Щёлкните фигуру и поле назначения или перетащите её. Клавиши со стрелками перемещают фокус, Enter выбирает поле. Часы продолжают идти по реальному времени, в том числе при сворачивании приложения. В партии без часов доступна отмена хода. Оформление доски, тема, звук и громкость находятся в настройках.

«Мои партии» открывает навигацию по ходам, PGN, быстрый и углублённый разбор. Можно прервать разбор и позднее продолжить с сохранённого полухода. Вариант «Что будет, если…?» открывается на отдельной доске. Настройки позволяют скачать и восстановить резервную копию. Профиль хранится на этом устройстве. После очистки данных браузера для восстановления потребуется копия.

## Архитектура и сборка

| Компонент | Назначение |
|---|---|
| `js/rules.js`, `js/game.js` | Общие для браузера и сервера генератор ходов, FEN, SAN, UCI, PGN, результат и часы |
| `js/board.js`, `js/audio.js`, `style.css` | Векторные фигуры, ввод, темы, звуки Web Audio |
| `js/engine.js`, `vendor/stockfish/` | Локальный однопоточный Stockfish в Worker, протокол UCI, отмена расчёта |
| `js/app.js` | Навигация, управление партией, экраны разбора и тренировок |
| `js/store.js` | Профиль, архив, миграция, резервные копии, расчёт рейтинга |
| `js/coach.js`, `js/lessons.js`, `data/puzzles.json` | Проверяемые объяснения, десять авторских дебютных уроков и сто задач |
| `js/online.js`, `server/main.js` | Приглашения, роли, синхронизация, постоянное хранение комнат в SQLite |
| `scripts/cache.js`, `scripts/worker.template`, `sw.js` | Генерация списка ресурсов и целостное обновление PWA |

После изменения клиентских файлов выполните `node scripts/cache.js`. Команда детерминированно генерирует `sw.js` по содержимому файлов. Фронтенд использует нативные ES-модули. Точные файлы движка, его исходники и лицензия входят в репозиторий.

## Данные и рейтинг

Старая запись `offline-chess-v1` остаётся доступной версии 1.0. При первом запуске приложение заново разыгрывает ходы и сверяет каждую позицию перед записью профиля `chess-profile-v1.1`. При следующих запусках используется готовый профиль. Выбран localStorage с компактной записью UCI-ходов, без копирования всей доски на каждый полуход. Размер длительной истории ограничен квотой браузера. Ошибки записи отображаются пользователю. Копии содержат SHA-256 и при восстановлении проходят проверку ходов.

Внутренний рейтинг начинается с 1200. После завершённой партии против компьютера применяется `round(24 × (S − E))`, где S равен 1, 0.5 или 0, а `E = 1 / (1 + 10^((Rсоп − R)/400))`. Ориентиры силы уровней — 700, 1100, 1500, 2000, 2500. Архив использует уникальный ID партии. Дружеские, импортированные и незавершённые партии не влияют на рейтинг. Рейтинг задач рассчитывается отдельно по первому результату, с коэффициентом 20.

Тренер использует локальную оценку Stockfish, проверяет продолжения общими правилами и описывает изменения позиции на русском языке. Для классификации сравниваются свободный поиск и поиск с заданным ходом на общей достигнутой глубине. Лучший ход совпадает с выбором движка. Потеря менее 50 сантипешек соответствует хорошему ходу, от 50 — неточности, от 100 — ошибке, от 200 — грубой ошибке. Мат имеет приоритет над материальной оценкой; учитывается знак и расстояние. Быстрый режим ограничен глубиной 10 и 450 мс, углублённый — глубиной 18 и 2 с на поиск. Разбор не использует настройки силы противника.
