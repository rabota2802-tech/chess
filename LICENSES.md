# Происхождение компонентов

- Stockfish.js — порт Stockfish от Chess.com и участников Stockfish, GPLv3. Используется облегчённая однопоточная сборка с именем **Stockfish.js 17** из тега порта **v17.1.0**, коммит [f9512ef9](https://github.com/nmrugg/stockfish.js/tree/f9512ef9aff391026813a56855dd086cb72a2d58). Встроенная в WASM сеть lite — nn-9067e33176e8.nnue. [Условия GPL](vendor/stockfish/Copying.txt), [исходники и средства сборки](vendor/stockfish/source.tar.gz), [контрольные суммы](vendor/stockfish/SHA256SUMS). Архив включает исходники соответствующей сборки, build.js, scripts, оригинальный README и lite-сеть. Для проверки полученных компонентов выполните из корня `shasum -c vendor/stockfish/SHA256SUMS`. Сохраняйте доступ к архиву и лицензии при распространении.
- Позиции задач и решения происходят из [базы Lichess, раздел Puzzles](https://database.lichess.org/#puzzles), CC0. Включены 100 записей с исходными идентификаторами, FEN, UCI-линией, темой и ориентиром сложности. Первый полуход задаёт позицию задачи. Идентификатор позволяет открыть задачу по адресу https://lichess.org/training/ID.
- Пояснения к дебютам, векторные контуры фигур и звуки созданы для проекта. Оригинальные контуры в js/board.js предоставляются для свободного использования, изменения и распространения по [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). Оригинальные иконки PWA и шахматные правила взяты из базового коммита самого проекта.
- Playwright 1.57.0 использован только для тестирования. Поставляемое приложение не включает Playwright.
