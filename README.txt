ШАХМАТЫ — установка на телефон и ноутбук

1. Распакуйте архив. Разместите index.html, sw.js, manifest.webmanifest и оба PNG в одной папке на HTTPS-хостинге. Не открывайте sw.js отдельно. Для локальной проверки на ноутбуке можно использовать localhost.
2. Откройте URL index.html при наличии интернета. Дождитесь загрузки страницы и обновите её один раз, чтобы сервис-воркер взял страницу под управление.
3. iPhone: Safari → Поделиться → На экран «Домой» → Добавить. Android: Chrome → меню → Установить приложение или Добавить на главный экран. Названия пунктов зависят от версии ОС. На ноутбуке можно установить приложение из Chrome/Edge либо использовать отдельный chess.html без хостинга.
4. Откройте установленную игру при наличии интернета один раз; затем включите авиарежим и проверьте повторный запуск. После кэширования интернет для игры не нужен. Данные партии сохраняются локально, между устройствами не синхронизируются. Очистка данных браузера может удалить кэш и партию.

Никаких внешних библиотек, аккаунтов или серверного движка. Уровни: новичок, средний, сильный. Сильный — наиболее сильный режим встроенного движка, не Stockfish и не рейтинг Elo.
