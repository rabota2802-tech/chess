# Откат

Стабильный коммит — `8659489ef9bc0a1d2c5104c9e602eac23ab6f53f`. Локальная метка — `baseline/chess-pre-v1.1`. Проверка — `git rev-parse baseline/chess-pre-v1.1`. На чистой рабочей копии для локальной проверки можно переключиться командой `git switch --detach baseline/chess-pre-v1.1`. Возврат к разработке — `git switch feature/chess-v1.1`.

Если владелец решит откатить уже опубликованный релиз, сохраните копию профиля 1.1 в настройках, остановите создание новых онлайн-партий и сделайте снимок SQLite. Разверните статические файлы прежнего коммита по прежнему адресу. Для новой установки со старой версией проверьте первоначальное кэширование. Для существующих устройств дайте браузеру получить прежний sw.js по сети, закройте открытые окна приложения и запустите снова. Убедитесь в автономном запуске и восстановлении исходной партии версии 1.0.

Версия 1.0 читает сохранённую при миграции запись offline-chess-v1. Новые партии версии 1.1 находятся в другом ключе и недоступны интерфейсу 1.0. Для них сохраняйте копию 1.1 и PGN. Удаление данных браузера или установленной PWA для отката не требуется. Отмена публичной версии и операции на инфраструктуре требуют согласования владельца.

## Откат публикации Pages с 1.1

Создать отдельный исправляющий коммит от опубликованного main. Восстановить index.html, обе иконки и manifest из метки baseline/chess-pre-v1.1. Для этих четырёх файлов сгенерировать sw.js по scripts/worker.template с SHA-256 содержимого и новым уникальным revision отката. Этот worker выбирает кэш по собственному имени и ждёт закрытия старых окон. Откатить все статические файлы и worker одним Pages-деплоем. Не применять force-push. Проверить содержимое нового sw.js через HTTPS, затем обновление уже установленного клиента, сохранение старого ключа и повторный запуск без сети. Сохранить экспорт 1.1 перед откатом; партии, сыгранные в период отката в 1.0, перед следующим переходом экспортировать отдельно.

Для серверного отката снять проверенную копию, выбрать предыдущий совместимый образ и текущий том chess-online_rooms. Если восстановление БД действительно необходимо, поднять копию в отдельном новом томе и проверить продолжение известной комнаты до переключения маршрута. Исходный том и снимки сохранить. С порядком остановки только этого проекта можно ознакомиться в VPS-PLAN.md.
