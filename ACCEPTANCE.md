# Приёмка на iPhone и MacBook

## Адрес и изоляция

Для локальной проверки на Mac используется отдельный стенд на http://127.0.0.1:18791/chess/. Этот loopback-адрес нельзя открыть с iPhone как адрес Mac.

Публичный production-адрес владельца остаётся за версией 1.0. У [GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages) один сайт на репозиторий. Даже ещё один проект Pages в том же аккаунте обычно получает другой путь на том же origin. localStorage и Cache Storage разделяются по origin. Для испытания используйте другое имя хоста. Тестовый пакет содержит пометку «Тест 1.1», отдельный manifest ID, собственную версию SW и отказ запуска на rabota2802-tech.github.io.

**Вариант бесплатного публичного размещения.** Статический пакет уже подготовлен. Его можно воспроизвести из ветки командой `node scripts/preview.mjs /tmp/chess-preview-new` (укажите новый каталог). Перенесите **содержимое** полученного каталога, включая .nojekyll, лицензии и исходники, на выделенный HTTPS-сайт. Для GitHub Free подойдёт публичный тестовый репозиторий Pages **другого согласованного владельца/организации** с другим доменом github.io. Прежняя установка и origin production для этого не используются. Сборка не содержит сервер, БД или данные игроков. Папка с другим именем на production-домене непригодна.

В качестве временной альтернативы **внутри проекта Chess** доступен [проброс порта GitHub Codespaces](https://docs.github.com/en/codespaces/developing-in-a-codespace/forwarding-ports-in-your-codespace). До создания пространства владелец проверяет оставшуюся бесплатную квоту и запрет платного перерасхода для вычислений и хранения. Правила учёта описаны [в справке GitHub](https://docs.github.com/en/billing/concepts/product-billing/github-codespaces). В пространстве на ветке feature/chess-v1.1 выполните:

```sh
node scripts/preview.mjs /tmp/chess-rc-site
python3 -m http.server 8080 --bind 0.0.0.0 --directory /tmp/chess-rc-site
```

В панели Ports откройте только 8080, выберите Public и скопируйте выданный HTTPS-адрес *.app.github.dev. С этого порта раздаётся только каталог тестового клиента. Пройдите начальный экран доверия GitHub, если он появится. Проверьте статус автономной готовности на каждом устройстве. После проверки закрыть публичный порт и удалить тестовое пространство, чтобы остановить расход квоты хранения. Онлайн-комнаты для удалённых устройств требуют отдельного согласованного сервера; для клиентских испытаний он не нужен.

## Проверка, около 10 минут на устройство

1. **Адрес.** Запишите текущий ход в установленной версии 1.0. Откройте отдельный тестовый HTTPS-адрес в Safari и убедитесь, что в шапке «Шахматы · Тест 1.1». На iPhone добавьте на экран «Домой» вторую иконку «Шахматы ТЕСТ».
2. **Партия.** Начните против компьютера с контролем 3+2. Сделайте ход, получите ответ, запишите последний ход и оба показания часов. Сверните на 15 секунд и вернитесь. Время должно уменьшиться только у стороны, чей ход. Закройте, откройте и нажмите «Продолжить партию».
3. **Тренер.** Откройте «?» рядом с ходом, затем «Что мне делать?». Сверьте фигуры и поля из пояснения с доской. На отдельной доске «Что будет, если…?» сыграйте другой ход и вернитесь: история основной партии должна совпадать.
4. **Автономность.** Дождитесь «Готово к офлайн-игре». Включите авиарежим на iPhone или отключите сеть на MacBook. Полностью переоткройте тестовое приложение; получите ход Stockfish, подсказку и задачу дня. При отключённом звуке проверьте отдельно положение аппаратного переключателя и настройки приложения.
5. **Управление и данные.** На iPhone проверьте касания и поворот экрана, на MacBook — перетаскивание и клавиатуру. Сделайте копию тестового профиля, измените тему и восстановите копию через «Настройки». Проверяйте восстановление только в тестовой версии.
6. **Раздельность.** Вернитесь в установленную 1.0. Сверьте записанный ход и вид доски. Для отчёта достаточно версии ОС/браузера, шага, ожидаемого и фактического результата. Токены комнат и резервную копию личных партий пересылать не требуется.
